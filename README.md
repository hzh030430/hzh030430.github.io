# hzh030430.github.io

Personal academic homepage for Zhuoheng Han.

## Local preview

Open `index.html` in a browser. No server or build step is required.

The site uses static HTML, CSS, and JavaScript, so GitHub Pages can publish the `main` branch without a build step.

## Maintenance

- Keep the existing section anchors and public publication links stable.
- Do not include unpublished submission titles, results, manuscripts, or a CV containing them without the author's approval.
- Publication status and personal contributions should match confirmed records; do not infer a venue from an arXiv date.
- The portrait, Manrope font, and a small Lucide icon subset are served locally. Licenses are in `assets/`.
- The page follows the system color scheme until the visitor chooses a theme. All content and navigation remain accessible without JavaScript.

## Design

An academic profile for researchers and recruiters, preserving the existing blue accent and navigation. Visual variance: 5/10; motion: 2/10; density: 6/10. The layout prioritizes a readable biography, public research, and identifiable personal contributions over a large hero.
